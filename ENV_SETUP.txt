ENVIRONMENT VARIABLES SETUP GUIDE
===============================================================

BACKEND (Render) - Environment Variables
===============================================================

Go to Render Dashboard → Your Web Service → Environment

Add these variables:

1. DATABASE (MySQL)
-------------------
MYSQL_HOST=your-mysql-host.render.com
MYSQL_PORT=3306
MYSQL_USER=your-db-username
MYSQL_PASSWORD=your-db-password
MYSQL_DATABASE=revenue_recovery

Where to get MySQL:
Option A: Render PostgreSQL (Free tier, recommended)
  - Dashboard → New → PostgreSQL
  - Copy connection details
  
Option B: PlanetScale (Free tier, MySQL)
  - Go to https://planetscale.com/
  - Create database
  - Get connection string
  
Option C: Railway (Free trial)
  - Go to https://railway.app/
  - New → MySQL
  - Copy credentials

2. RAZORPAY CREDENTIALS
-----------------------
RAZORPAY_KEY_ID=rzp_test_YOUR_KEY_ID
RAZORPAY_KEY_SECRET=YOUR_SECRET_KEY
RAZORPAY_WEBHOOK_SECRET=your_strong_random_secret

Get from: https://dashboard.razorpay.com/app/keys

3. LLM API KEYS (At least one required)
---------------------------------------
GROQ_API_KEY=gsk_YOUR_KEY
GEMINI_API_KEY=AIza_YOUR_KEY

Get Groq key (Free): https://console.groq.com/keys
Get Gemini key (Free): https://makersuite.google.com/app/apikey

4. OPTIONAL SETTINGS
--------------------
MAX_RETRY_ATTEMPTS=3
AUTO_ACTION_THRESHOLD=10000
HIGH_VALUE_THRESHOLD=50000
LLM_TEMPERATURE=0.1

COMPLETE BACKEND ENV VARS (Copy-paste to Render):
--------------------------------------------------
MYSQL_HOST=your-mysql-host
MYSQL_PORT=3306
MYSQL_USER=your-db-user
MYSQL_PASSWORD=your-db-password
MYSQL_DATABASE=revenue_recovery
RAZORPAY_KEY_ID=rzp_test_YOUR_KEY
RAZORPAY_KEY_SECRET=YOUR_SECRET
RAZORPAY_WEBHOOK_SECRET=your_webhook_secret
GROQ_API_KEY=gsk_YOUR_KEY
GEMINI_API_KEY=AIza_YOUR_KEY
MAX_RETRY_ATTEMPTS=3
AUTO_ACTION_THRESHOLD=10000

FRONTEND (Vercel) - Environment Variables
===============================================================

Go to Vercel Dashboard → Your Project → Settings → Environment Variables

Add ONE variable:

NEXT_PUBLIC_API_URL=https://your-backend-app.onrender.com

(Replace with your actual Render backend URL)

IMPORTANT: 
- Must start with NEXT_PUBLIC_ to work in browser
- No trailing slash
- Use HTTPS (Render provides this automatically)

MYSQL DATABASE SETUP - EASIEST OPTIONS
===============================================================

OPTION 1: PLANETSCALE (Recommended - Free MySQL)
-------------------------------------------------
1. Go to https://planetscale.com/
2. Sign up (free tier includes 5GB)
3. Click "Create Database"
4. Name: revenue_recovery
5. Region: ap-south (Mumbai) or closest to you
6. Click "Create"
7. Go to "Connect" → Select "General" → Copy credentials

Connection details:
  MYSQL_HOST=aws.connect.psdb.cloud
  MYSQL_PORT=3306
  MYSQL_USER=your-username
  MYSQL_PASSWORD=your-password
  MYSQL_DATABASE=revenue_recovery

8. Add these to Render environment variables
9. Database will auto-create tables on first run

OPTION 2: RENDER POSTGRESQL (Free but PostgreSQL not MySQL)
------------------------------------------------------------
If you want to use PostgreSQL instead:

1. Render Dashboard → New → PostgreSQL
2. Name: revenue-recovery-db
3. Free tier
4. Click "Create Database"
5. Copy "Internal Database URL"
6. Add to backend env:
   DATABASE_URL=postgresql://user:pass@host:port/dbname

Then update backend code to use PostgreSQL instead of MySQL.

OPTION 3: RAILWAY (Free Trial)
--------------------------------
1. Go to https://railway.app/
2. Sign up
3. New Project → MySQL
4. Copy connection details
5. Add to Render env vars

OPTION 4: AIVEN (Free Tier)
----------------------------
1. Go to https://aiven.io/
2. Sign up
3. Create MySQL service (Free tier available)
4. Copy connection details

TESTING AFTER DEPLOYMENT
===============================================================

1. Test Backend Health:
   curl https://your-backend.onrender.com/health
   Should return: {"status":"ok","version":"0.3.0"}

2. Test MySQL Connection:
   Backend logs will show if MySQL connected successfully
   Look for: "Application startup complete" (no errors)

3. Test Frontend:
   Open: https://your-app.vercel.app
   Should load dashboard (may show 0 data initially)

4. Trigger Demo Data:
   curl -X POST https://your-backend.onrender.com/trigger-demo-recovery
   Then refresh frontend

===============================================================

COMMON ISSUES
===============================================================

"MYSQL_HOST not configured":
- Make sure env vars are set in Render
- Restart the service after adding vars

"Cannot connect to MySQL":
- Check host/port/credentials are correct
- Verify MySQL service is running
- Check firewall/IP whitelist (PlanetScale needs no whitelist)

Frontend shows "Backend not responding":
- Check NEXT_PUBLIC_API_URL is correct
- Verify backend is deployed and running
- Check backend logs for errors

"API key invalid":
- Regenerate keys from respective dashboards
- Update in Render env vars
- Restart service

PLANETSCALE SETUP (STEP BY STEP)
===============================================================

1. Go to https://planetscale.com/
2. Click "Get Started" → Sign up with GitHub
3. Click "Create a database"
4. Database name: revenue_recovery
5. Region: AWS / ap-south-1 (Mumbai)
6. Click "Create database"
7. Click "Connect" button
8. Select "General" (not framework specific)
9. Copy these values:

   Host: aws.connect.psdb.cloud
   Username: [shown in dashboard]
   Password: [shown in dashboard, click "Generate password"]
   Database: revenue_recovery

10. In Render, add env vars:
    MYSQL_HOST=aws.connect.psdb.cloud
    MYSQL_PORT=3306
    MYSQL_USER=[your-username]
    MYSQL_PASSWORD=[generated-password]
    MYSQL_DATABASE=revenue_recovery

11. Deploy! Tables will be created automatically.

✅ PlanetScale is FREE and works perfectly for demos!
